# email-helper

Private, rule-based Gmail sorter: a PWA (GitHub Pages) + a Google Apps Script backend. $0, no AI.

**Status:** Phase 0 — design exploration.

- `design/concepts/` — 5 HUD concepts (static, mock data) + icon sheet
- `design/icons/` — 3 icon options (SVG + PNG at iOS sizes)
- `design/screenshots/` — iPhone-size (390×844 @3x) screenshots
- Regenerate: `node design/shoot.mjs` and `node design/export-icons.mjs`
